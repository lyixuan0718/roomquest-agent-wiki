# Python Verifier

## 核心概念

AI Model 負責有彈性的生成，Harness 負責限制、工具與停止條件。凡是可以明確寫成規則的問題，不需要再問另一個模型猜一次。

## RoomQuest 應用

Verifier 檢查物品存在、條件唯一、順序可解、安全動作、答案來源固定與 JSON schema。若「窗邊、紅色」同時符合水壺與書包，唯一性檢查失敗；加入「可裝水」後才剩一個候選物品。

## 限制

規則只檢查已建模的資料。它不能判斷照片外的物品，也不能完全保證自然語言沒有歧義，因此最後仍保留主持人核准。

## 檢查問題

- 這項判斷能否寫成 deterministic rule？
- 驗證失敗時能否回報具體欄位與原因？
- 程式是否擅自替模型補資料？
